# Code of conduct

We want shell.online to be a focused, welcoming project where people can disagree constructively and ship useful work.

## Our standards

Be respectful, specific, and generous with context. Critique ideas and code rather than people. Do not harass, threaten, discriminate against, dox, or deliberately expose another person's terminal data, credentials, or identity.

## Scope

This applies in repository discussions, pull requests, issue trackers, and other public spaces where someone is representing the project.

## Enforcement

Report conduct concerns privately to the repository owner through [GitHub](https://github.com/TeoSlayer). Do not open a public issue containing personal or sensitive details. The maintainer may edit or remove contributions and temporarily or permanently restrict participation when necessary to keep the project safe.

Reports will be handled as confidentially and promptly as practical. Good-faith reporters will not face retaliation.
