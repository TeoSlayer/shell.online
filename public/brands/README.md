# Brand artwork

These marks identify third-party terminal tools and operating systems. They do
not imply endorsement, affiliation, or that desktop-only interfaces are shared.
Muse Code uses its publisher Meta's mark; Solaris uses Oracle's mark.

- Agent SVGs: [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), MIT; license included in `LICENSE-lobe.txt`.
- macOS, Linux, BSD marks: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), CC0; license included in `LICENSE-simple-icons.txt`. Windows and Oracle use the collection's 11.0.0 versions.
- DragonFly BSD: [official project artwork](https://www.dragonflybsd.org/images/DragonFly_BSD.svg).
- Aider: [official project logo](https://github.com/Aider-AI/aider/blob/main/aider/website/assets/logo.svg).
- Droid: [Factory favicon](https://factory.ai/favicon.svg).
- Hermes: existing application artwork, reused from `app/public/icons/hermes.png`.

Marks remain the property of their respective owners. All assets are served
locally; the landing page makes no third-party logo requests.

The setup picker uses explicit launch commands in `web/landing-brands.ts`, not
lowercased brand names. In particular, [Cursor](https://docs.cursor.com/en/cli/overview)
uses `cursor-agent`, [Goose](https://github.com/block/goose/blob/main/documentation/docs/quickstart.md)
uses `goose session`, and [OpenClaw](https://docs.openclaw.ai/cli/tui) uses
`openclaw tui`. Meta's [Muse installer](https://dev.meta.ai/install.sh) names the
launcher `muse`. These examples assume the agent is already installed and
configured; individual agent platform support and subscriptions differ.
